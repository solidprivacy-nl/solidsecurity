# 60-Day Supplier Remediation Plan — Synthetic Beta

## Days 0–30

- inventory non-human/service accounts, document authentication mechanism and include them in access recertification;
- commission/update independent application penetration testing or formally agree customer-acceptable recency evidence;
- complete the overdue subprocessor security/privacy review;
- complete risk/vendor assessment for the support AI summarizer;
- define customer incident-notification answer as a contract-specific response template rather than a universal promise.

## Days 31–60

- exercise wider service continuity beyond database restore, including identity/cloud/support dependencies;
- add dedicated SolidSecurity controls for secure software development, cryptography/key management, and security logging/monitoring before scaling the supplier questionnaire product;
- create evidence expiry dates for every passport claim;
- establish a reusable approved-answer library where each answer stores provenance, approved wording, evidence references, validity window and professional-review requirement.

## Target commercial outcome

A future customer questionnaire should become mostly a mapping/reuse exercise: identify semantic matches to approved answers, attach still-valid evidence, surface exceptions and reserve only contract-specific/material assertions for professional review.
