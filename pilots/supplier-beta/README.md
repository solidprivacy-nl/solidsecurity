# Service MVP B — Synthetic Supplier Beta

Status: `SYNTHETIC / PROPOSED RESPONSES / NO INDEPENDENT ASSURANCE`

This dossier tests the SolidSecurity Supplier proposition against a fully fictional Dutch SaaS/IT supplier serving healthcare customers. The customer questionnaire is internally authored and contains no real customer confidential content.

## Goal

Demonstrate that recurring customer security questionnaires can be answered from a reusable control/claim/evidence backbone while preserving uncertainty and professional review boundaries.

## Workflow

1. define synthetic supplier scope;
2. create reusable supplier baseline and evidence set;
3. ingest an internally authored 20-question security questionnaire;
4. map each question to controls/evidence;
5. generate proposed answers with provenance and review flags;
6. publish a proposed Security & Compliance Passport;
7. identify gaps/remediation;
8. model effort/reuse and record architecture lessons.

## Governance

- Work contract: issue #9.
- Stacked on Foundation V1 PR #3.
- No questionnaire answer is an independent assurance statement.
- No ISO/NEN certification or NIS2/Cbw compliance claim is made.
- All organization/evidence facts are synthetic.
