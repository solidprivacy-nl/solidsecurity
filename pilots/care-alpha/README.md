# Service MVP A — Synthetic Care Alpha

Status: `SYNTHETIC / IMPLEMENTATION CANDIDATE / PROFESSIONAL REVIEW NOT PERFORMED`

This dossier executes the SolidSecurity Care workflow against a deliberately fictional small Dutch home-care organization. It contains no real client data, credentials, domains, evidence or protected NEN/ISO requirement text.

## Purpose

Test whether the SolidSecurity managed-service operating model can produce a reconstructable baseline without a GRC application or customer-environment connector.

## Governance

- Work contract: issue #5.
- Stacked on Foundation V1 PR #3.
- All assessments are `PROPOSED` by implementation operations.
- No proof level 4 (`Verified`) or 5 (`Independently Assured`) may be assigned by this pilot.
- Direct legal applicability of Cbw/NIS2, GDPR provisions, AI Act categories, NEN 7510 or certification criteria is not decided by this synthetic exercise.

## Workflow executed

1. synthetic intake and fact pack;
2. Care Baseline V1 applicability;
3. implementation claims;
4. synthetic evidence catalogue;
5. proposed control assessments;
6. findings and evidence requests;
7. 90-day remediation plan;
8. draft governance artifacts;
9. draft customer baseline report;
10. effort model and lessons learned.

## Files

- `organization.yaml` — synthetic organization facts and scope;
- `care_baseline.yaml` — applicable SolidSecurity controls;
- `evidence_catalog.yaml` — synthetic evidence items;
- `assessment.yaml` — control-by-control proposed assessment;
- `findings.yaml` — gaps and contradictions;
- `supplier_register.yaml` — synthetic suppliers;
- `ai_register.yaml` — synthetic AI-use cases;
- `EVIDENCE_REQUEST.md` — requested evidence to move claims upward on the Proof Ladder;
- `REMEDIATION_90D.md` — prioritized first 90 days;
- `BASELINE_REPORT.md` — customer-facing draft;
- `effort_ledger.yaml` — separated AI/customer/professional effort hypothesis;
- `LESSONS.md` — model and workflow feedback;
- `drafts/` — generated governance drafts. Draft existence never proves implementation.
